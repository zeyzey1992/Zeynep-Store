Zeynep Store 🛍️

A clothing store web application built with React and Node.js. Users can browse products, view product details, filter products by category, and manage their shopping cart.

Features

Product Dashboard: Display products fetched from the DummyJSON API.

Product Details: View product images, descriptions, and prices.

Shopping Cart: Add products, remove items, and increase or decrease quantities.

Cart Total: Automatically calculate the total price based on product quantities.

Categories: Browse categories using a dropdown menu and view products by category.

Light and Dark Mode: Switch between light and dark themes. The selected theme is saved using localStorage.

Navigation: Navigate between pages using React Router.

Responsive Product Layout: Display products using reusable React components.
